# ⚖️ DR Danielle Silva — Advocacia

Site institucional para escritório de advocacia em Jarinú, SP.
Desenvolvido com HTML, CSS e JavaScript puro — sem frameworks.

---

## 🖥️ Tecnologias

- HTML5 semântico
- CSS3 Mobile First (tema claro/escuro)
- JavaScript ES6+ puro
- Remix Icon 4.6.0 (CDN)
- Google Fonts — Cormorant Garamond + Inter

---

## 📑 Seções

- Hero
- Sobre
- Serviços (6 áreas de atuação)
- Depoimentos (carrossel)
- Galeria (lightbox)
- Agendamento (envio via WhatsApp)
- Contato (Google Maps)
- Footer

---

## 🚀 Como rodar

```bash
# Clone o repositório
git clone https://github.com/seu-usuario/dr-danielle-silva-advocacia.git

# Abra no navegador
open index.html
```

Ou use a extensão **Live Server** no VS Code.
